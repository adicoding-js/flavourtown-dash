# Flavortown Dash 🌮

A cool fun Geometry Dash clone built for **flavortown.hackclub.com**. Experience rhythm-based platforming action directly in your browser with zero delays.

## 🎮 Features

- **Core Gameplay**: Fully immersive Cube and Ship physics.
- **Level Editor**: Build, playtest, and export your own levels with an easy to use grid-based editor.
- **Custom Skins**: Upload any image to play as your own custom character.
- **Zero Delay Input**: Optimized input handling with jump buffering for responsive gameplay.
- **Cross-Platform**: Fully responsive design that works on Desktop and Mobile.

## 🛠️ Tech Stack

- **Engine**: Custom Vanilla JS Game Engine (Canvas API)
- **Audio**: Web Audio API for precise timing and analysis
- **Build Tool**: Vite

## 🚀 Getting Started

1.  **Clone the repo**
    ```bash
    git clone https://github.com/adicoding-js/flavourtown-dash.git
    cd flavourtown-dash
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Run development server**
    ```bash
    npm run dev
    ```

4.  **Build for production**
    ```bash
    npm run build
    ```

## 🎨 Level Editor

Access the editor from the main menu to create custom challenges.
- **Tools**: Spikes, Blocks, Portals (Ship/Cube), Finish Lines.
- **Shortcuts**: `Z` to Undo, `Y` to Redo, `Shift + Drag` to Pan.
- **Storage**: Levels are saved locally and can be exported as `.json` files.
